PyRogue -- third-party notices
==============================

PyRogue itself is MIT-licensed (see LICENSE). This download also contains
other people's software and art, listed below with their licences. The full
licence texts are in the licenses/ folder next to this file.

Most of the libraries come bundled inside pygame-ce 2.5.8, the library the
game window is built on. The list was taken from the pygame-ce 2.5.8 wheels
for Windows (win_amd64) and Linux (manylinux x86_64); "Linux only" marks the
ones the Windows build doesn't include. Licence texts were taken from each
project's official repository on 2026-10-13.


Replacing the LGPL libraries
----------------------------
pygame-ce, and on Linux also mpg123, FluidSynth, libsndfile and alsa-lib, are
licensed under the GNU Lesser General Public License v2.1. They are shipped
as separate files inside the _internal folder (not compiled into the game),
so you can replace them with your own builds of the same libraries. Their
source code is available from the URLs below; pygame-ce's is at
https://github.com/pygame-community/pygame-ce/tree/2.5.8 .
