PyRogue (browser build) -- third-party notices
==============================================

PyRogue itself is MIT-licensed (see LICENSE). This download also contains
other people's software and art, listed below with their licences. The full
licence texts are in the licenses/ folder next to this file.

The browser build runs the game on pygbag 0.9.3's WebAssembly runtime (CPython
3.12 and pygame-ce 2.5.7 compiled with Emscripten), which is copied into this
zip under rt/. The runtime is a set of prebuilt binaries, and its authors
publish no bill of materials for them. This list was compiled from the
runtime's published build recipes (pygame-web/python-wasm-sdk, pygbag, the
pygame-ce 2.5.7 source tree) and from inspecting the files (version strings,
symbol names and source paths found inside them). It is NOT an audit of the
binaries. Where a component's presence or version could not be confirmed, the
row says "may be present" or "version not verified"; components that the
desktop build ships but that left no trace in the browser binaries (libpng,
libjpeg-turbo, libtiff, libwebp, FLAC, Opus, mpg123, WavPack, libxmp,
FluidSynth) are left out. Licence texts were taken from each project's
official repository on 2026-10-28 (SDL_gfx.txt is pygame-ce's own note from
its tag 2.5.7 licence folder, and Timidity.txt is the README that carries
Timidity's licence choice); where a text is identical to the desktop
build's it is the same file.


Replacing the LGPL parts
------------------------
pygame-ce is licensed under the GNU Lesser General Public License v2.1, and
so is SDL2_mixer's bundled Timidity if you take it under the LGPL (it is
offered under the GPL, LGPL or Artistic licence; this build uses the LGPL).
In the browser build pygame-ce is a separate file, not compiled into the
interpreter:

    rt/cp312/pygame_ce-2.5.7-cp312-cp312-wasm32_bi_emscripten.whl

A wheel is a zip archive. You can replace it with your own build of the same
library: build pygame-ce 2.5.7 for Emscripten (Python 3.12) from
https://github.com/pygame-community/pygame-ce/tree/2.5.7 , name the result
exactly as above, put it in rt/cp312/ in place of the original and zip the
folder again with index.html at the root. The page loads the interpreter and
this wheel from rt/ at start-up (rt/index-0.9.3-cp312.json names it), so no
other file needs to change. The libraries listed under "pygame-ce wheel"
below are linked statically inside that one wheel, and are replaced with it.
The recipes that built the stock wheel are in
https://github.com/pygame-web/python-wasm-sdk and
https://github.com/pygame-web/pygbag .
